# CruxCoach 0.2.5 RC1 walk: report

Build 1000052, commit 7272058. The walk ran on the test phone on 16 and 17 November 2026.

Each area got three passes:
- **DE:** German, light theme, font scale 1.0. This is the full functional walk.
- **dark + largest font:** German, dark theme, font scale 2.0, done as one pass. It checks layout and contrast.
- **EN:** English, light theme, font scale 1.0. It checks texts and wording.

Segments done: s1 (update with data, main screens, backup and export), s2 (training and nutrition), s3 (statistics and year in review), s4a (Shiny Wall, wall games without a board), s4b (community, hold types, Quantum, LED effects, board size check, PaintBox), s5 (spray walls, relay traffic), s7 (fresh install: first launch and setup, twice), the training quick start (in a fresh test app with the RC1 training code, because the release app's first visit was used long ago), and s6 (the board simulator).
The simulator segment ran on 17 November in a test app with the RC1 board code, so that the release app stayed freshly set up for the maintainer. The Kilter simulator (12x12 with kickboard) reports **Aurora API level 3** ("Kilter Board#0001@3"). Its LEDs were not observed: lighting is judged from the app and its log. Three earlier scans had found no board; the simulator was restarted before the fourth.

The crash log was empty in every segment, apart from the two out-of-memory crashes of bug 4.
Apart from the test spray walls (published, then withdrawn and deleted), nothing was sent from the app: no bug report, rating or post. Every share sheet was cancelled.
